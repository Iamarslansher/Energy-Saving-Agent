# ⚡ Energy Saving Agent

**Developed by Arsalan Sher — BSCS-6/C**

## 📌 Overview

The **Energy Saving Agent** is a simple intelligent agent designed to promote efficient energy usage. It analyzes the current situation and provides appropriate actions or recommendations to reduce unnecessary energy consumption.

## 🎯 Objective

The main objective of this project is to demonstrate how an intelligent agent can make decisions based on predefined conditions and help users save energy.

## 🤖 Agent Type

**Type:** Rule-Based Agent

The agent follows predefined rules to analyze different situations and make energy-saving decisions.

### Example Rules

* If a device is not in use → **Turn it OFF**
* If no person is detected → **Turn unnecessary devices OFF**
* If energy usage is high → **Recommend reducing consumption**
* If natural light is sufficient → **Turn lights OFF**

## 🛠️ Technologies Used

* Python
* Rule-Based Logic
* Conditional Statements

## ⚙️ How It Works

1. The user provides information about the current environment.
2. The agent checks the given conditions.
3. It matches the conditions with predefined rules.
4. The agent selects an appropriate action.
5. It displays an energy-saving recommendation.

## 💡 Example

**Input:**

```text
Room occupied: No
Light: ON
Fan: ON
```

**Agent Decision:**

```text
💡 Light should be turned OFF.
🌀 Fan should be turned OFF.
⚡ Energy can be saved.
```
